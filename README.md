## 香港 VPS 的优惠码，实际只有三类

先分类，再看别人整理的清单，能省掉一半试错。

**第一类：产品线循环折扣码（Recurring）。** 绑定某个产品线和某个付款周期，季付或年付才生效，续费同样享受折扣。这类码最值钱，也最容易被人抄来抄去抄到过期。

## 优惠码具体怎么填

流程不复杂，但第一步走错就白搭——月付周期是填不进去的。

1. 在购物车页面选好套餐，点进配置页；
2. 选付款周期，把 Billing Cycle 改成季付、半年付或年付；
3. 进入结算页，找到 Promo Code 输入框；
4. 填入优惠码，点 **Validate Code**；
5. 看订单总额有没有变化，有变化再点结算。

Validate 失败的两种情况要分清：码本身过期了，或者码有效但不适用于你选的产品线和周期。第二种情况换个周期再试一次往往就成了。

## 为什么你收藏的码第二天就失效了

四个原因，按出现频率排：

- **产品线和付款周期双绑定。** 同一个商家有 Pro、T1、EB 多条线，各自发各自的码，混用必然失败。
- **不叠加、仅限新订单、不适用于已有服务。** 这三条限制在 DMIT 的活动公告里是写明的。
- **活动窗口短。** 补偿类活动的有效期常常只有几天到一个多月。
- **商家更愿意用特价机型控库存。** 香港机房总量就那么多，与其发通用折扣码，不如把机器做成特价款定向投放。这也是为什么很多"香港 VPS 优惠码"文章最后推荐的其实是一台特价机。

## 几个高频问题

**优惠码能用在续费上吗？** 只有 Recurring（循环）类可以。非循环码只对首单生效，第二年就恢复原价了，算总成本时一定要区分。

**能和其他活动叠加吗？** 不能。官方公告里明确写了不可叠加。

**月付能用优惠码吗？** 香港这边的公开码基本都要求季付及以上。想省钱就从付款周期开始改。

**超了流量会被停机吗？** T1 系列不会，降速继续用。Pro 系列的流量给得比较紧张，TINY 档 500GB，建站 + 图床这类场景要记得估算。

**支持哪些付款方式？** 支付宝、PayPal、国际信用卡都可以，对国内用户来说比纯信用卡的商家省事。
